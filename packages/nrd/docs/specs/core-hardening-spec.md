## A. Конформанс-пакет формата

Новая директория `test/conformance/`. Пакет фиксирует канон (docs/specs/format-spec.md) исполняемо. Минимум:

1. **last-wins по ленте** (§2.4): повтор `$key` в root и в блоке — побеждает последний; позиция атрибута в ленте свободна (после сообщений, между блоками).
2. **Каскад блоков** (§8): повтор блока по id — last-wins; getAttr/resolveName/resolveBlockName уже реализованы, зафиксировать тестами.
3. **Эскейпы:** `\$key:` в начале строки тела — литерал; `\${` — литеральный `${` (разворачивается ровно один раз, §3.1); `\.` в путях внутри `${}` (§7.1).
4. **Round-trip:** `parse(serialize(doc)) ≡ doc` на корпусе: документ с блоками, вложенными блоками, flow-массивами, quoted-скалярами, телами содержащими строки вида `$key: value`, `## $name`, `%role`.
5. **Quote-семантика** (после фикса B2): `"..."` — сила только в позиции скаляр-литерала (значение атрибута целиком, аргумент выражения); в произвольном тексте кавычка — просто символ.

Часть round-trip тестов упадёт до B — помечать `.fails`/todo, снимать пометку по мере фиксов B. Это осознанный порядок: тесты фиксируют целевое поведение.

## B. Фиксы (ревью 03.07, живые №1–4)

**B1. Двойной unescape тела (parser flushBody).** Тело хранить raw до финальной склейки, unescape применять ровно один раз на выходе. Найти оба места unescape, оставить одно. Регрессия: тело с `\\$` и `\\##`.

**B2. Quote-skip глушит плейсхолдеры.** `scanPlaceholders` (placeholder.ts, «Skip quoted region») пропускает `${}` внутри `"..."` при top-level скане. Убрать skip из скана произвольного текста: resolve сканирует ВСЁ. Кавычки остаются грамматикой только в coerce (скаляр-литерал) и в parseArgs (строковый аргумент). Обязательный тест-кейс (живой инцидент 07.07):
```
resolve('{"model": "${model}", "no_think": ${think}}', {model: 'x', think: false})
→ '{"model": "x", "no_think": false}'
```

**B3. Round-trip x-storage (serialize).** `serializeBody`: строка тела, начинающаяся с `$слово:`, `## $`, `#... $` или `%слово` — экранируется `\` перед первым символом при serialize; parser уже понимает `\$` (после B1 — ровно один unescape). Добавить симметричный unescape для `\##` и `\%` если отсутствует. Критерий — round-trip корпус из A4 зелёный.

**B4. parseInlineAttrs: `$` внутри значения рвёт атрибут.** Инлайн-атрибут распознаётся только по паттерну «пробел + `$` + слово + `:`» (` $word:`). `Fee costs $5 total` перестаёт рваться. Регрессия: значения с `$`, суммы, `a $b: c` (валидный атрибут после пробела).

Не в скоупе: №7 console.warn, №8 split()-стаб — не трогать.

## C. Расширения резолва (решения 07.07, «Слоистые контексты»)

**C1. Правило скоупа (задокументировать в format-spec, поведение уже такое):** скоуп резолва = цепочка, переданная читателем. Атрибуты блока НЕ являются неявным скоупом для плейсхолдеров внутри него. Голый `${x}` — свободная переменная (параметр), заполняет читатель.

**C2. `self` — зарезервированный корень путей.** `${self.x}` — ссылка на составную единицу, в которой текст живёт. Композитная семантика: при чтении контента блока `self = chainContext(атрибуты блока, extends-база если есть)`; на root-уровне `self` = сам документ. Реализация: при резолве значения атрибута/тела блока в цепочку подкладывается слой `objectContext({self: <композит>})`. self внутри значения ключа K не видит K через self? — НЕТ, видит (цикл ловится существующим cycle guard, ошибка). Тесты: self.x из блока, self из root, self сквозь extends (переопределение наследника видно базе — virtual dispatch), цикл `$a: ${self.a}` → ошибка.

**C3. `$nr-extends: <path.mdz>` — блочное наследование.** Семантический атрибут (грамматика НЕ меняется). При построении контекста блока: `chainContext(атрибуты блока, parseDocument(file))` — own-wins, база = дефолты. Файл резолвится относительно документа-владельца. Ленивая загрузка, БЕЗ кэша в ядре (ревью 14.07): ядро stateless/IO-free, а ключом кэша мог бы быть только сырой путь — который загрузчик резолвит относительно своей директории, так что `base.mdz` из разных документов коллизировал бы. Мемоизация — зона ответственности `ExtendsLoader`. В пределах одного вызова база грузится максимум один раз. Отсутствующий/битый файл — ошибка (fail loud, НЕ молча). Резолв контента — по C1+C2. Тест — сквозной сценарий из DECISIONS (preset/server-x: `$json` c `${self.model}`/`${if_else(self.think,false,true)}`, переопределение model/think, чтение потребителем).

**C4. Конвенция `nr-`:** атрибуты с префиксом `nr-` — системные директивы, интерпретируются слоями выше, никогда не данные пользователя. Задокументировать в format-spec. `cast('attrs')`/keys их НЕ фильтруют (данные видны), фильтрация — дело потребителя.

**C5. stdlib чистых функций** — новый `src/functions.ts`, экспорт `coreFunctions: Record<string, FuncFn>` (+ реэкспорт в index):
- `if_else(cond, a, b)` — truthy-ветвление (false/null/undefined/'' → b)
- `not(x)`, `eq(a, b)` (строгое, с коэрцией типов НЕ занимается), `default(x, fallback)` (x===undefined/null → fallback)
Только чистые, ноль IO — IO остаётся в nrd-context (граница доверия = граница пакета). Тесты на каждую + вложенность `${if_else(eq(mode,"a"), 1, 0)}`.

**C6. Обновить docs/specs/format-spec.md:** §скоуп-резолва (C1), §self (C2), §nr-extends (C3), §nr-префикс (C4), уточнение quote-семантики (B2), stdlib-приложение (C5).
