# examples/resolve — проверка резолва

Прогонять из корня rz: `runz rz examples/resolve/<file>`

Не демонстрации «как надо» — **зонды**. Каждый файл проверяет один узел цепочки
резолва. Тремя из них были найдены дефекты (DEBT 08.08); после все
зонды зелёные и закреплены тестами: `test/examples.test.ts`.

## chain.mdz — CLI → атрибут документа → путь источника → код

| прогон | результат |
| --- | --- |
| без аргументов | DOC-FILE |
| `--slug=from-cli` | CLI-FILE |
| env `slug=from-config` | DOC-FILE |
| конфиг `slug=from-config` | DOC-FILE |
| `--slug=from-cli` + env/конфиг | CLI-FILE |

`helpers.attr` и `${}` совпадают во всех прогонах.

Каскад: **`CLI > документ > app-конфиг > глобальный конфиг > env`**. Раньше был
`(CLI + конфиги + env) > документ` — посторонняя переменная окружения молча
уводила источник на другой файл. Починка: runz отдаёт слои цепочки раздельно
(`ScriptMeta.chain`), rz кладёт документ между ними (`strongChain`/`weakChain`
в nrd-context).

## deps.mdz — источник, зависящий от источника

`registry` читает список ботов, `bot` берёт путь из `${registry.active}`,
`label` собирает строку из полей `bot`. Работает: атрибуты блока читаются об
**накопленную** цепочку, а не об params.

## forward-ref.mdz — ссылка вперёд

`label` объявлен выше `registry` и ссылается на него → громкая ошибка с именем
звена. Порядок звеньев декларативен: звено видит только объявленные выше.
Циклических ссылок не вводим.

## inline-forms.mdz — две формы inline-звена

| форма | `${who}` |
| --- | --- |
| атрибуты (`$text: привет ${who}`) | резолвится |
| тело + `parse: mdd` | резолвится |

Инвариант приёмки: обе формы дают одинаковый результат. Раньше телесная отдавала
`[object Object]` — значение оставалось InterpolatedValue и утекало объектом,
**молча**.

## probe.mdz — что лежит в значении

`JSON.stringify(ctx.get(['a','text']))` → `"привет мир"` (было `{}`).

## inline-dep.mdz — тело inline-звена и предыдущее звено

Тело видит предыдущее звено: `parseRaw` получает цепочку и резолвит значения
лениво, об неё.

## Грабля: `$body:` — это атрибут, а не тело

```mdz
## $source label
$nr: {type: 'inline', parse: 'mdd'}
$body: |            # ← атрибут `body`, тело блока пустое
  @text: ...
```

Тело блока — то, что идёт после пустой строки (как в `inline-forms.mdz`).
`$body:` попадает в атрибуты обычным ключом; зарезервированный слот тела —
служебный (`$body` в `attrs`, кладёт ядро). Два зонда изначально были написаны
с `$body: |` и выглядели как ещё один дефект резолва — им не были.
