# examples/forge — makefile-форма и композиция

Прогонять из корня rz: `runz rz examples/forge/<file>`

Зонды закреплены тестами: `test/examples.test.ts`.

## build.mdz — однородная сборка инклудами

Инклуды внутри тела блока-источника: три mdz-фрагмента склеиваются last-wins
в одно именованное звено `bot`. Пресет перекрывает `traits` персоны, остальное
складывается.

```
bot.name    : Carly
bot.traits  : сдержанная, но упрямая   ← preset поверх personality
bot.setting : летняя трасса, переезд
```

Вывод: overlay/merge как отдельные примитивы не нужны — их даёт порядок инклудов.

## mixed.mdz — разные форматы в одном звене

json и mdd подключаются в звено функциями `${loadJSON(...)}` / `${loadMDD(...)}`:

```
typeof bot.preset     : object
isContext(bot.preset) : true
bot.preset.temperature: 0.9
bot.lore.city         : Мидленд
```

Здесь было три дефекта подряд (DEBT 08.08 №4–6), все закрыты в:

1. одинарные кавычки в аргументе (`loadJSON('./x.json')`) — теперь легальны,
   как в json5-атрибутах; незакрытый литерал жалуется на литерал, а не на путь;
2. относительный путь резолвится от **папки документа** — как инклуды и
   `$path:` источника (baseDir доезжает до функции служебным путём, а не голым
   ключом пользовательского неймспейса, который никто не заполнял);
3. плейсхолдер, занявший значение целиком, оставляет **дерево** деревом —
   поддерево монтируется под именем, а не схлопывается в строку.

## fn-forms.mdz — поле результата vs монтирование поддерева

```
поле .temperature : 0.9          ← ${loadJSON('./parts/preset.json').temperature}
поле .style       : из json-пресета
целиком → дерево  : true         ← ${loadJSON(json)}
из дерева .max_tokens : 512
```

Path-доступ после вызова (`call ('.' segment)*`) грамматика раньше запрещала —
`Expected '.' between path segments`. Без него монтирование дерева было
половинчатым: дерево есть, адресоваться внутрь нечем.

**Итог:** композиция разных форматов работает — карточка json/mdd ложится рядом
с mdd-исходником в одно звено. Трансформы для оверлея форматов по-прежнему не
нужны: хватает порядка инклудов и last-wins.
