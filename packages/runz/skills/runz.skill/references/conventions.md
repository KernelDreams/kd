# conventions — как здесь принято писать код

Сквозные правила: чего держаться в любом скрипте, appz или либе. Сюда — когда
сомневаешься «как принято»; нарушение жёстких правил = переделка на ревью.

## Сначала найди, что уже есть

**Перед тем как писать механизм — проверь роутер в `SKILL.md`.** Свой парсер
конфигов, шаблонизатор или HTTP с ретраями — велосипед.

## Жёсткие правила

- **Ядро stateless и IO-free.** Платформа (fs/exec/http) инъектируется через
  capabilities и loaders; кеш — забота загрузчика, не либы.
- **Fail loud.** `Result` где принято, иначе явный throw; никаких молчаливых
  `undefined` и проглоченных исключений — подозрительный успех хуже падения.
- **Данные — в `meta.dataDir`,** пути не хардкодить и рядом с исходником не писать.
- **Тесты — часть «готово», не опция.** Чистая логика без теста не сделана (как их
  гонять — ниже).
- **Ошибка пользователю — в stderr и ненулевой exit**, не в `output`.

## Node и пути

- Node 24+, нативный TS: **без tsx, ts-node, компиляции**; **ESM only**, `require()`
  запрещён; `enum` запрещены — `as const`-объекты.
- Все пути — относительные или от `~`: абсолютный путь, скопированный руками,
  размножается и тухнет, а ведущий `~` runz раскрывает сам. Корень студийного
  дерева — `~/Studio`: `appz/`, `nrlib/`, `Projects/`, `skills/*.dev`.
- Секреты в код и документацию не пишутся — только **имя** секрета и где его взять.

## Тесты

**Тесты — часть определения «готово».** Только `node:test`:
`node --test test/*.test.ts`, ассерты `node:assert/strict`, снапшоты
`t.assert.snapshot`; **никаких vitest/jest/сборщиков/конфигов раннера**. Чистая
логика (парсинг, трансформации, резолв путей) — тест обязателен; интеграционная
обвязка (сеть, LLM, глобы) — довольно фикстуры с прогоном в README.

Гонять — `runz test`, не `node --test` напрямую: у appz нет `package.json`, и файл
с `import … from '@kerneldreams/nrd'` упадёт на резолве. `runz test` — тот же
`node --test` с resolve-хуком runz и его `$paths`:

```
runz test                    # тесты в cwd
runz test greet              # цель по имени из $paths
runz test . --filter=detect
```

Берутся `*.test.ts`/`*.test.mts` рекурсивно (без node_modules/dist). Пустой набор и
ненайденная цель — exit 1, а не зелёный прогон ни по чему. Запускать тест скриптом
(`runz ./test/x.test.ts`) нельзя: требует default export, глотает вывод, exit 0.

## README — док-стандарт

Обязателен у каждого appz и либы. (1) **Первый абзац** — назначение одним
абзацем, самодостаточно: он уходит в каталог машинно, без остального текста;
(2) команды с примерами вызова; (3) особенности, зависимости, грабли. CHANGELOG не
ведём — история в git; внутренние документы README не линкует.

## Коммиты

- **Коммить каждое осмысленное состояние, включая непроверенное.** Незакоммиченное —
  единственное невосстановимое состояние; откат дешевле повторного накатывания.
- Закончил кусок (фикс, фичу, правку) → коммит сразу, не спрашивая.
- Непроверенное или сломанное — коммит с пометкой `WIP` / `unverified` в сообщении.
- Чужой незакоммиченный WIP в дереве → отдельный коммит `WIP (unattributed)` ДО
  своей работы.
