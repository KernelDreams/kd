# Синтаксис mdz / mdd / mds — выжимка для подсветки

Производное от `nr-system.dev/use/references/formats.md` (канон — спеки репо `nrd`). Здесь — только то, что нужно редактору для подсветки. Семантику (резолв, каскад, cast) редактор не исполняет.

## Сигил

- `.mdz`, `.mds` — сигил `$` (исполнение, конфиг).
- `.mdd`, `.md` — сигил `@` (данные).
- Грамматика одинаковая, различие только в сигиле. Строка с чужим сигилом — обычный текст.
- Ниже примеры на `$`; для mdd подставь `@`.

## Заголовок блока

```
## $name            блок типа name
## $name some-id    блок с id
### $child          уровень = число решёток = вложенность (h1–h6)
## $@               закрытие блока (короткая форма: ## $)
## $site.ru         точка в имени литеральна
```

Имя: `[A-Za-z_][A-Za-z0-9_.-]*`. `## $$` — невалиден (не подсвечивать как блок). Заголовок без сигила (`## Обычный`) — обычный markdown.

## Атрибут

```
$key: value
$a.b: 1             один ключ "a.b", точка литеральна
$nr-type: file      ключи nr-* — системные директивы
```

Ключ: `[A-Za-z_][A-Za-z0-9_.-]*`, строка начинается с сигила, затем ключ, затем `:`. Значение — до конца строки.

Подтипы значения (для разных классов подсветки):

```
$flag: true / false / null
$n: 42   -7   3.14          числа (+42 и 007 — строки)
$s: "в кавычках"            строка
$list: $[a, b, c]            flow-список (сигил + [), $[] — пустой
$cfg: {model: 'gpt', n: 2}   JSON5-объект: значение начинается { и кончается }
$lit: \{not json}            эскейп — строка
```

## Плейсхолдеры и инклуды

```
${a.b.0}  ${fn(a, b)}  ${a.${b}}    плейсхолдеры, в любом месте строки, с вложенностью
\${x}                               НЕ плейсхолдер (литерал)
$[[path]]  $[[path#Section]]  $[[#Section]]   инклуд файла/секции
{{user}}                            макрос шаблонизатора — не ${}, отдельный класс или без подсветки
```

## Эскейпы

`\$` `\@` сигил · `\[` скобка · `\${` литеральный `${` · `\\` · `\.` · `\,` · `\{` в начале значения. Эскейпнутое не триггерит разметку.

## Комментарий

```
$// это комментарий до конца строки
```

## Таблицы (tbl) в теле

Строки с `|` в теле блока; первая строка — заголовок с типами (`weight:number | tags:list(;) | rare:boolean!`), `//` — комментарий. Подсветка опциональна (разделители `|`, типы в заголовке).

## Сообщения (.mds и тела)

```
%user
текст сообщения
%assistant
ответ

````%thinking
opaque тело, внутри ничего не размечать
````
```

`%role` в начале строки — конверт. Типизированный фенс — ЧЕТЫРЕ бэктика + `%type`, закрывается четырьмя бэктиками. Три бэктика — обычный markdown-фенс.

## Пример .mdz

```
$title: Bot Fix
$model: ${models.default}
$tags: $[rp, fix]

## $step load
$src: $[[cards/base.mdz#Persona]]
$nr-type: file

### $param depth
$value: 4
$// глубина вставки

## $@

## $step save
$dst: out/${self.name}.md
$cfg: {retries: 2, strict: true}

Тело блока — обычный **markdown**, live preview работает.
```
