# nr-editor

Редактор текстовых файлов kd на CodeMirror 6.

- Задача и все решения — `docs/SPEC.md`. Спека закрыта: делать, не переобсуждать. Неясность — одно конкретное решение в духе спеки, записать его в PR.
- Синтаксис mdz/mdd/mds для подсветки — `docs/mdz-syntax.md`.
- Язык общения, комментариев к PR и отчёта — русский. Код и идентификаторы — английский.
- Не велосипед: сначала готовые пакеты CM6 / Atomic Editor / codemirror-ts, своё — только синтаксис mdz.
- Сырой текст — источник правды; round-trip байт в байт обязателен.
- Сдача — PR в `main`, описание кончается «Приёмкой глазами» со скриншотами.
